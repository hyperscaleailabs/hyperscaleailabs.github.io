Case studies and working cores, published rather than described. Each one is a piece of the same argument: probabilistic systems need the same rigour we already give to distributed ones.

Everything lives under github.com/hyperscaleailabs. Repositories are added to this page by editing assets/data/projects.json.

—Context

Why these exist in public.

The production versions of this work sit behind employment. What can be shared is the shape of it — the harness, the control loop, the evaluation gate, the failure taxonomy — reconstructed from first principles so the reasoning is inspectable.

If something here is useful, take it. If something here is wrong, an issue is welcome.
